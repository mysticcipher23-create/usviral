# USViral

Daily blogs on the 25 biggest United States searches of the past 24 hours, ranked by search volume. Each edition is dated in US Eastern time. The writing and the pictures are original. USViral is not affiliated with Google.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local site
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run typecheck` — TypeScript check
